# PPT 演讲稿（ppt-speech-script）

> 把幻灯片变成人话，而不是把幻灯片念一遍。

一个给 AI Agent 用的 skill。它解决一个很常见的问题：**让 AI 根据 PPT 写演讲稿，它就直接把每页的标题和要点复述一遍**——听着像念稿，台下没人想听。

装上它之后，AI 会做两件不同的事：

1. 动笔**之前**先问你：想做成哪种风格？（商务汇报 / 路演 / 答辩 / 教学 / 故事 / 动员 / 极简提词），或者你说"你决定"，它自己按场合选并声明理由。
2. 写稿**过程中**守住一条底线：幻灯片上的字是提示物，讲稿必须是信息增量；每页都得补一条屏幕上没有的东西。

## 它治的病

| 常见表现 | 为什么难听 | skill 怎么拦 |
|---|---|---|
| "这一页我们看到，Q3 复购率 42%，同比增长 8 个百分点" | 观众自己会读，你在浪费他们的时间 | 标题/要点原文不得作为完整句子出现在口播里 |
| "第一……第二……第三……" | 把并列条目念成清单 | 并列条目必须讲成因果、递进或对比 |
| 页与页之间硬切 | 听众跟不上主线 | 每页结尾必须有一句过渡 |
| 一页讲 30 秒，十页讲 15 分钟 | 时长失控 | 按 220–260 字/分钟估算，合计落在目标 ±10% |
| 通篇"综上所述""旨在" | 书面语，念出来打结 | 平均句长 ≤ 25 字，书面语一律替换 |

## 两个核心机制

### 1. 风格闸门（铁律 0）

生成任何一句演讲稿之前，必须先确定风格。**除非**用户已在请求里指定风格，或明确说"你决定 / 你自己发挥"。

需要确认时，一次问完（风格 + 时长 + 听众 + 目标），不要连环追问；风格没定就不写正文，也不先写"通用稿"再改。

### 2. 反照读规则（铁律 1）

- 不复述：标题、要点原文不得作为完整句子出现在口播里，要提就转成"这意味着……"
- **每页补一个屏幕上没有的东西**：原因、例子、数字含义、对比、风险、代价、下一步。补不出来，说明这页该删或合并——直接告诉用户，别硬写
- 长名词短语改成口语句：`提升跨部门协同效率` → `以前一个需求要过三个部门，现在拉个群两天就能定`
- 页与页必须有桥
- 元话语（"如幻灯片所示""这一页我们看"）全篇合计最多 1 次

## 安装

把本仓库的 `SKILL.md` 放进你所用客户端的 skills 目录，**目录名与 `SKILL.md` 里的 `name` 字段保持一致**（`ppt-speech-script`）。

常见位置（以你的客户端文档为准）：

| 客户端 | 路径 |
|---|---|
| DeepSeek Harness | `~/.dsh/skills/ppt-speech-script/SKILL.md` |
| Claude Code | `~/.claude/skills/ppt-speech-script/SKILL.md` |

PowerShell：

```powershell
git clone https://github.com/<you>/ppt-speech-script.git "$env:USERPROFILE\.dsh\skills\ppt-speech-script"
```

macOS / Linux：

```bash
git clone https://github.com/<you>/ppt-speech-script.git ~/.dsh/skills/ppt-speech-script
```

装完新开一个会话，技能会被自动加载；之后丢一份 PPT 说"做个演讲稿"即可。

## 用法

```
这是季度复盘 PPT，帮我写一份 8 分钟的演讲稿，听众是部门负责人
```

AI 会先回你一个风格选项（带推荐项和一个"你帮我定"），定完再逐页出稿：

```
风格：商务汇报型｜总时长约 8 分钟｜听众：部门负责人

### 第 3 页 · 增长来自复购（约 45 秒）
**口播**：……
**过渡**：……（接到下一页）
**提示**：（此处停顿两秒 / 切到图表）
```

结尾附时长汇总表。若你要写进 PPT 备注，它会走对应客户端的 PowerPoint 技能（如 `office-pptx` / `pptx`）用 python-pptx 写入，而不是手工拼 XML。

## 内置风格

| 风格 | 适合场合 | 语言特征 |
|---|---|---|
| 商务汇报型 | 周会、立项、复盘、对上汇报 | 结论先行，数字带口径，少形容词多因果 |
| 路演说服型 | 融资、产品发布、对外合作 | 痛点—代价—方案—证据—行动 |
| 学术答辩型 | 论文答辩、技术评审 | 问题—方法—实验—局限，主动交代边界 |
| 培训教学型 | 内训、上手教学、SOP 宣讲 | 先场景后步骤，每步配"做错会怎样" |
| 故事叙述型 | 年会、分享会、品牌宣讲 | 具体的人、时间、细节，冲突在前 |
| 感召动员型 | 誓师、动员、闭幕 | 短句、排比、第二人称 |
| 极简提词型 | 熟手复讲、时间紧 | 每页 3–5 个关键词 + 一句转折 |

表里没有的风格（如"轻松幽默"），把用户原话当文风约束执行，并在输出第一行声明。

## 正反例

**PPT 上写的**：`Q3 复购率 42%，同比 +8pct`

**照读（错）**
> 这一页我们可以看到，Q3 复购率是 42%，同比增长了 8 个百分点。

**讲稿（对）**
> 42% 这个数字，比数字本身更重要的是它涨了 8 个点——这是我们第一次把拉新预算砍掉三成还实现增长，说明留住老客比买新客便宜。

## 兼容性

`SKILL.md` 正文里不写死任何单个客户端的工具名，而是写"当前环境可用的提问工具 / PowerPoint 技能"并附常见名称（`ask_user_question` / `question`，`office-pptx` / `pptx`）。换客户端不用改文件。
